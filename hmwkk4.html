Welford recurrence and sampling mean / variance

Ex. 1 – The recurrence (core logic: 3 lines)

for (let k = 1, M = 0, SS = 0; k <= n; k++) {
  const d = x[k-1] - M;     // 1. innovation
  M  += d / k;              // 2. Knuth: new mean
  SS += d * (x[k-1] - M);   // 3. Welford: new sum of squares
}                           // sample variance = SS / (n-1)
Mk = Mk−1 + (xk − Mk−1)/k  ·  SSk = SSk−1 + (xk − Mk−1)(xk − Mk)  ·  s²k = SSk/(k−1). Derivation in the written report.
